# 📌 About Project

Motion Tracker CCTV is a real-time computer vision project that can detect and track different human movements through a camera feed.

The system can identify:

- 😀 Face Motion Tracking
- ✋ Hand Tracking
- 🧍 Body Pose Tracking
- 🎥 CCTV Motion Detection
- 📍 Real-Time Landmark Tracking
- ⚡ Live Camera Processing

This project demonstrates practical use of AI-powered tracking and motion detection technologies.

---

# ✨ Features

### 😀 Face Tracking
- Detects human faces
- Tracks face movement in real-time
- Displays face landmarks

### ✋ Hand Tracking
- Tracks hand position
- Detects finger movement
- Real-time hand landmark visualization

### 🧍 Body Tracking
- Detects full body posture
- Tracks body points
- Real-time pose estimation

### 🎥 CCTV Motion Detection
- Detects movement in camera feed
- Highlights moving objects
- Useful for surveillance systems

### ⚡ Real-Time Processing
- Live webcam support
- Fast response
- Smooth tracking experience

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/yourusername/motion-tracker-cctv.git
```

Move into project folder

```bash
cd motion-tracker-cctv
```

Install dependencies

```bash
npm install
```

Run frontend

```bash
npm run dev
```

Run backend

```bash
npm start
```
